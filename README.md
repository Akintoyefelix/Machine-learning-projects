# Machine Learning Projects

A curated collection of machine learning projects covering various domains, problem types, and inference workflows.  
Each subfolder in this repository contains a **self-contained project** with:
- Problem description
- Data preprocessing
- visualization
- Model training & evaluation
- Inference / deployment example (API,Streamlit, notebook, or script)

---
